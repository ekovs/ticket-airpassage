# Система учета заявок на авиабилеты (ticket-airpassage)

Проект для автоматизации учета заявок на авиабилеты, разработанный в рамках освоения навыков создания консольных Java-приложений со слоистой архитектурой и методов функционального тестирования.

Программа обеспечивает ведение учета авиабилетов, хранение данных в виде списка, добавление новых записей, удаление, а также поиск заявок по номеру рейса и желаемой дате вылета.

### Стек технологий и окружение
- **Язык разработки:** Java (JDK 19)
- **Сборщик проектов:** Maven
- **Среда разработки:** IntelliJ IDEA

### Архитектура проекта
Логика приложения разделена на несколько независимых слоев для обеспечения чистоты и удобства поддержки кода:
1. **Слой данных (Model):** класс `com.ekovs.model.Ticket`. POJO-класс, содержащий структуру заявки: пункт назначения, номер рейса, имя пассажира и дату вылета.
2. **Бизнес-логика (Business Logic):** сервис `com.ekovs.model.BookingService`. Содержит реализацию основных операций — добавление в список, удаление и поиск.
3. **Доступ к данным (Data Access):** репозиторий `com.ekovs.repository.UserRepository`. Отвечает за persistence-слой. Реализовано чтение и запись данных в текстовый файл `tickets.txt` в кодировке UTF-8 для сохранения состояния между сеансами работы.
4. **Интерфейс (Interface):** класс `com.ekovs.Main`. Консольное интерактивное меню программы для взаимодействия с пользователем.

### Тестирование и отказоустойчивость
В рамках проекта проведено комплексное ручное тестирование:
- Составлены чек-листы и тест-кейсы для проверки основных функций (добавление, поиск, удаление, сохранение).
- Настроена валидация пользовательского ввода — добавлена обработка исключений (включая перехват `NumberFormatException`), что предотвращает аварийное завершение программы при вводе некорректных данных и запрашивает их повторно.
- Верифицирована корректность кодировки при работе с кириллицей в итоговом файле данных.

Программный продукт полностью стабилен, успешно прошел проверку по тест-кейсам и соответствует техническим требованиям.
